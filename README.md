# E-Learnify


E-learnify is a web-based e-learning platform designed for B.Sc. and BCA Computer Science students. It provides structured courses with study materials, quizzes, and PDF notes to help learners gain both academic knowledge and practical skills in computer science subjects.

⸻

🚀 Features
	•	User-friendly course enrollment system
	•	Subject-wise course materials (PDF notes, video lectures, descriptions)
	•	MCQ-based quizzes for self-assessment
	•	Progress tracking for learners
	•	Teacher support for uploading and managing courses
	•	Secure login and user authentication

⸻

🛠 Tech Stack
	•	Frontend: HTML, CSS, JavaScript
	•	Backend: PHP
	•	Database: MySQL
	•	Server: Apache (via XAMPP/WAMP)
	•	Editor: Visual Studio Code

⸻

📂 Modules
	•	Courses – Subject-wise content with PDF notes and descriptions
	•	Quizzes – MCQ-based quizzes with scoring
	•	Notes – Well-structured downloadable PDF study material
	•	User Management – Student registration, login, and authentication

⸻

🔮 Scope for Future Improvements
	•	Leaderboard and badge system for gamified learning
	•	AI chatbot for student support
	•	Coding environment integration for practice
	•	Dynamic video player
	•	Research/thesis sharing module for teachers
	•	Course certifications

⸻

📖 Getting Started
	1.	Install XAMPP/WAMP server
	2.	Import the provided MySQL database
	3.	Place project files inside the htdocs folder
	4.	Run the project using http://localhost/e-learnify
